Build a .l2d from scratch (no Studio required)

A .l2d file is a plain ZIP archive containing layer2d.json, pack.json, RGBA textures in tex/, and SHA256SUMS.json. You can build one directly with Python or JavaScript and drop it straight onto the Player or Studio.

Raw Markdown version for AI agents: layer2d.com/agent-guide.md.

1. Required archive layout

starter.l2d├─ layer2d.json       # format: "layer2d/v1", canvas, stats, capabilities (ZIP_DEFLATED)├─ pack.json          # runtime layers, yaw samples, physics, expressions (ZIP_DEFLATED)├─ tex/               # RGBA .png or .webp textures (ZIP_STORED, uncompressed)│  ├─ H01.png│  ├─ B01.png│  ├─ F01.png│  └─ H03C.png├─ preview.png        # optional portrait thumbnail (ZIP_STORED)└─ SHA256SUMS.json    # SHA-256 hex digest for every other archive member (ZIP_DEFLATED)

pack.json schema

All geometry uses canonical canvas: [W, H] pixels (origin top-left, +X right, +Y down). samples[k].layers[i] is parallel-indexed to layers[i].

KeyStructure & contract
canvas / views[W, H] master resolution; views.bust and views.full framing rects [x0, y0, x1, y1].
headcentre, radius, eu/ev axes, chin, neck, jawNear, pivot (neck rotation), turn: {R, L} (radians, e.g. -0.22 / +0.22).
layers[]Ordered back-to-front: id, w, h, kind (0 head, 1 torso, 2/3 arms R/L, 4 skirt, 5 hips/tail, 6 leg), head, optional parent (Group Node ID or Layer ID for transform & opacity inheritance), clip, clipTarget, behind: [maskA, maskB], pad, chains, chainSigma, pitchGroup.
nodes[]Optional Scene Graph Transform / Deformer Groups: {id, name, parent?, pivot: [x,y], inheritOp?}. Supports arbitrary parent → child nesting (cycle-checked, topological O(N) propagation) with rest-pose-zero relative transform & opacity inheritance. Animate groups across samples[].nodes[id], pitchSamples[].nodes[id], and blendShapes[].nodes[id] using {dt, dRot, dScale, dOp}.
samples[]Sorted ascending by angle. Each layer entry has A: [a0,a1,a2,a3], t: [tx,ty], op, optional turn, binary occlusion behind (0 or 1), inverse warp grid D, or forward vertex mesh F (2 × gd², gd ∈ {3,5,7,9,11}), plus optional nodes deltas.
pitchSamples[]Optional Angle Y keyforms sorted by pitch (-1.0 .. +1.0) with per-layer layers[id] and per-group nodes[id] deltas (dt, dRot, dScale, dOp, F).
blendShapes[]Optional additive deformers: {id, name, min, max, default, bind?, layers: {id: delta}, nodes?: {id: delta}}. Live bind drivers: mouthOpen, eyeOpen, eyeX, eyeY, breath, angleX, angleY, angleZ (and expression faces[].blend).
pitchGroupsMap of layerId → "face" | "bangs" | "side" | "crown" | "back" | "ear" | "humanEar" for vertical head look parallax.
chains[]Multi-joint spring chains: name, parent ("head" | "body" | "hips" | "armR" | "armL"), k: [root, tip], damp, joints: [x0,y0, x1,y1, …] (2–6 joints), depth, pin.
tailOptional rigid pelvis-locked tail: {id, pivot: [x,y], amp, freq, happyFaces}.
outfitsNamed toggles: {label, default, hide: [ids], off: [dx,dy], secs}.
exprpieces (static overlays or flipbook atlas: {cols, rows, fps, intro, loop, pad}), faces (hide, add, move, eyes, look), holds (hide, add, still, face), blink ({hide, add, drop, squash}), and vowels: {A, I, U, E, O}.

Agent authoring guide & lessons learned

Practical engineering rules distilled from building multi-layer production rigs. Follow these when generating or rigging avatars autonomously:

  • Never crossfade hair (op = 1.0 always). Alpha-fading hair across turns creates translucent ghosts. Separate hair into solid physical depth shells — back (H01), crown fill behind ears (H02c), mid depth (H02/H02s), under-bangs (H03u), side locks (H04s/H04), and front bangs (H03C/R/L) — with signed parallax.
  • Never flip behind near center yaw (a = 0) over the forehead or brows. The WebGL2 runtime applies behind as a hard binary mask (>= 0.5 ? 1 : 0). Toggling 0 ↔ 1 near center makes under-bangs snap visibly above eyebrows. Keep under-bangs (H03u) outside the eyebrow X-band and lock depth shells (H02c/H03u/H02s/H04s) permanently to behind = 1.0 at all angles; transition far-side locks (H04) only after they clear the cheek edge (|u| >= 0.28).
  • Keep crown fill behind animal ears. For kemonomimi ears, draw crown fill shells behind ear layers and keep the dome top below ear roots so dark hair triangles never cover white inner ear fluff. Set pitchGroups[id] = "ear" so vertical pitch pivots cleanly at skull roots.
  • Inverse warp grid (D) sign convention & padding. The shader samples texture coordinates at g_tex = g_screen + D(g_screen). Moving rendered pixels by +Δg means subtracting Δg from D. Keep pad generous (320–420 px) so warped tips never clip against the layer quad.
  • Rigid tail rotation beats spring chains on fluffy tails. Multi-segment Voronoi chains bend thick animal tails like wavy fabric with segment creases. Use pack.tail with pure rigid rotation around the pelvis pivot (no per-frame non-uniform sx/sy stretch).
  • Topological clipping masks. Set clipTarget: true on every layer referenced by another layer's clip or behind (for example F01 and sclera E01R/L). The runtime topologically sorts parent masks before child masks automatically.
  • Pose-arm holds & expressions. Place forehead gloom/mood shades high above the browline. In holds, hide every replaced resting arm/sleeve layer and lock its spring with still: ["armR"]. Force eyes = 1.0 when capturing expression QA tiles so random blinks never ruin a sheet.
  • Use true 3D partial masking on socks, sleeve cuffs & tubular bands. Never draw an uncut hollow back-rim ellipse on top of an entering limb or neck. Split socks (S01R/L), sleeve cuffs (J05R/L, C04R/L), and bands along their curved front-lip parabola into <ID>_back behind the limb and <ID> (front lip only) in front, and include <ID>_back in outfits and body.elbowHalf.
  • Seal bare shoulders (jacket OFF), smooth neck-to-head transitions & fill open-arch shoes wall-to-wall. Keep bare shoulder ridges/armpits 100% opaque (alpha = 255) and tangent to the torso collarbone slope (0 px V-notch); trim any flared jaw stub off neck B01 so it enters F01 smoothly; and smoothly flare lower sock insteps (map_coordinates) so shaded sock fabric fills open-arch shoes (Mary Janes) wall-to-wall with zero gaps or internal sock outlines.
  • Keep face layer F01 stem-free & ear-free, add the full 3D side-of-head stack (F02tR/L, F01sR/L, F03tR/L + lush H02s/H04s side hair), sculpt eyes & keep body motion solid (like Test Signal). Never leave a hanging neck stem below F01's chin outline or baked-on side ears on F01. Always build the full 3D turn-head depth stack via rigkit.face3d (face3d.py): clipped rear-to-front directional face shading (F02tR/L), sleek straight-angled side-of-jaw planes (F01sL/R, jaw_depth_px=14–20, placed immediately after F02tR/L with matched shading), sculpted 3/4 nose layers (F03tR/L as front F03 yields to 0), and lush multi-strand side-of-skull hair curtains (H02s/H04s unfolding rearward behind graceful cheek-framing locks H04). Keep irises & pupils (E02/E03) centered slightly inward inside sleek wider almond sclera (E01) with curved lower lashes (E06) sculpted snugly to the eye shape. For crisp body movement without rubbery torso squish, omit motion.turnChain and use Test Signal-style subtle bodyFollowLR: [0.025, 0.025] and limit.bend: 0.25.
  • Audit attachment polish & auto-generate fix prompts across every outfit toggle. Run python3 polish_audit.py avatar.l2d --out polish_out/ --prompt (bundled in the Agent Testing Kit, or python3 -m rigkit.polish) across both default and outer-garment-OFF states. It scores attachment quality 0–100, renders zoomed close-ups (polish_audit.png), and generates a pixel-exact polish_fix_prompt.txt so even less experienced agents can fix every defect until FAIL=0 and score >= 92.
  • Run a visual Playwright QA loop before shipping. Render headless WebGL2 turn sweeps across both wide angles (-1.0 .. +1.0) and fine center angles (-0.40 .. +0.40), plus pitch grids, expression sheets, and ?obs=1 top-corner alpha checks (alpha === 0), and inspect the rendered images directly.

Full standalone agent specification & starter builder script: https://layer2d.com/agent-guide.md.

User QA checklist & how to tell your AI to fix defects

Even with frontier models, your first pass will often have subtle attachment bugs. First run python3 polish_audit.py avatar.l2d --out polish_out/ --prompt and paste polish_fix_prompt.txt back to your AI — then check these 6 high-impact visual details in Studio or Player:

What to inspectWhat to tell your AI agent
Hollow sock / sleeve / band back rims over skin"Apply partial masking to socks (S01R/L) and sleeve cuffs (J05R/L): split each along its front-lip parabola into <ID>_back behind the limb and <ID> (front lip only) in front, and add <ID>_back to outfits and body.elbowHalf."
Shoulder gap / V-notch with jacket toggled OFF"Toggle the cardigan/jacket OFF with hair hidden. Keep the top shoulder ridge & armpit 100% opaque (alpha=255), seat B03R/L tangent to B02's collarbone slope for 0px V-notch, and map bare arms in body.elbowHalf."
Stair-step or gap between neck & head"Trim the flared upper jaw stub off neck B01 down to slender mid-neck width so it rises smoothly behind F01's chin with zero step, and fade only the bottom collarbone edge into B02."
Socks not filling open-arch shoes wall-to-wall"Composite shoes S02R/L on bright green. Smoothly flare lower sock insteps (y >= 0.66h) with map_coordinates (not binary dilation) so shaded sock fabric fills the shoe arch wall-to-wall with zero gaps or internal sock outline."
Face neck stem or double human ears (F01 + F05/F06)"Inspect F01 alone on green. Strip any hanging neck stem below the chin outline (so nothing swings off B01 on head turns) and erase baked-on side ears from F01 so ONLY separate F05/F06 ears remain."
Unfocused / wall-eyed gaze looking sideways"Run polish_audit.py --prompt to check eye_gaze_focus. Shift irises & pupils (E02/E03) inward toward the nose bridge for zero outward divergence, and align E04 highlights to one consistent key light."
Oversized choker / belt / misaligned limbs"Resize choker A03 to 1.00–1.10× neck width, tuck halter straps behind the choker, seat belt K01 flush on K02, and anchor-solve all limb joints within < 2px."
Hair pops over brows or ear drift on turns"Run qa_runner.py and inspect qa_turns_center.png & qa_pitch_grid.png. Lock hair op=1.0, lock depth shells to behind=1.0 across all yaw angles, put crown fill behind animal ears, and pad quads >= 320px."

Studio

Layer2D Studio runs 100% client-side in your browser — open any .l2d bundle or import a layered Photoshop .psd directly, sculpt warp grids and lattice cages on yaw keyforms, edit draw order, clipping, behind occlusion, spring chains, tail pivots, expressions, flipbook FX, and keyframe animations, then export a SHA-256-verified .l2d bundle with optional non-destructive studio.json metadata.

Player

The Layer2D Player runs entirely in the browser on WebGL2. Nothing is uploaded.

  • Drag an .l2d file onto the page to load it.
  • Webcam tracking drives head turn, gaze and blinks.
  • Microphone input drives lip sync with selectable Phoneme (LPC formant + consonant/plosive detector), Basic (3-band AEIOU), or Volume modes.
  • Expressions, outfits and holds are selected from the panel.

OBS Browser Source

Add a Browser source in OBS and point it at the player with ?obs=1. OBS mode renders on a transparent background with premultiplied alpha (no green screen needed) and hides the interface.

# Recommended (zero self-hosting, no OBS flags, works with private local .l2d files):# 1. Open https://layer2d.com/player/ in Chrome/Edge, drop your .l2d, enable Mic & Cam# 2. Click "OBS Link" — paste the copied URL into an OBS Browser Source:https://layer2d.com/player/?obs=1&link=l2d-xxxxxxxxxxxx# Or point directly at a hosted .l2d URL:https://layer2d.com/player/?model=test-signal.l2d&obs=1
  • OBS Link (P2P) + Synced OBS Audio Tunnel: Because OBS's embedded Browser Source blocks webcam/mic permissions and OS file drag-and-drop by default, clicking OBS Link in your regular browser streams your .l2d once directly peer-to-peer (cached locally in OBS's IndexedDB, never uploaded to any server) and mirrors live webcam tracking, expressions, outfits, and poses into OBS at 60 fps with true transparent alpha.
  • Keep voice & mouth frame-synchronized in OBS: With OBS Audio: ON (the default when OBS Link + Mic are active), your mic audio is tunneled over WebRTC into the OBS Browser Source. Enable Control audio via OBS on the Browser Source and mute your separate raw OBS mic input (to avoid duplicate audio). Inside OBS, phoneme detection analyzes the incoming stream ahead of a configurable Web Audio DelayNode (the Sync slider, default 90ms) so the delayed voice output and avatar mouth emerge from the exact same OBS source in lockstep — with zero local headphone echo in your browser tab.
  • Set width and height to match your canvas, for example 1080 × 1920.
  • Prefer Window Capture instead? Click BG: Green in the browser player for a pure #00ff00 chroma-key backdrop.

CLI

The rigkit.format module packs, inspects, validates and unpacks bundles using Python's standard library.

# pack a viewer directory (pack.json + tex/)python -m rigkit.format pack models/demo/viewer demo.l2d \  --meta avatar_spec.json --preview preview.png# print the manifest summarypython -m rigkit.format inspect demo.l2d# verify structure, textures and SHA-256 digestspython -m rigkit.format validate demo.l2d# extract safely after validationpython -m rigkit.format unpack demo.l2d out/

validate exits with status 1 on any error, so it can gate CI.
